How It Works & Mathematical Principles

An IPv4 Subnet Calculator computes network address, broadcast address, first and last usable host IPs, subnet mask, wildcard mask, and total usable host count from any IPv4 address and CIDR prefix (/0 to /32), including RFC 3021 /31 and /32 routes.

Classless Inter-Domain Routing (CIDR) partitions 32-bit IPv4 space into network bits (prefix /N) and host bits (32 − N). Reserving the all-zeros network ID and all-ones broadcast address leaves 2^(32 − CIDR) − 2 usable hosts on /0–/30 networks, while /31 provides 2 point-to-point addresses (RFC 3021) and /32 designates a single host route.

Governing Equation
Usable Hosts = 2^(32 - CIDR) - 2 (/0–/30) | /31 = 2 P2P Hosts (RFC 3021) | /32 = 1 Host

Step-by-Step Worked Calculation Example

Scenario: Calculating subnet boundaries and host capacity for IP 192.168.1.50 with prefix /24.

  • Host bits = 32 - 24 = 8 bits ⇒ 2^8 = 256 total IP addresses.
  • Subtract network (.0) and broadcast (.255): 256 - 2 = 254 usable host IPs.
  • Network ID = 192.168.1.0/24; Broadcast = 192.168.1.255; Usable range = 192.168.1.1 – 192.168.1.254.

Result: 254 Usable Host IPs (192.168.1.1 – 192.168.1.254)

Bitwise ANDing IP with subnet mask 255.255.255.0 isolates the exact .0 network boundary even when starting from mid-subnet host IPs like .50.

Forgetting to Subtract Network and Broadcast Addresses on Small Subnets

A /29 block contains 8 total addresses, leaving only 6 usable host IPs (not 8).

Frequently Asked Questions

Why are 2 IP addresses subtracted in 2^(32 − CIDR) − 2?

In standard IPv4 subnetting, the very first address identifies the network itself and the very last address serves as the subnet broadcast address, leaving 2^(32 − CIDR) − 2 usable host IPs.

What happens with /31 and /32 CIDR prefixes?

A /32 represents a single host route (1 address), while RFC 3021 defines /31 point-to-point router links using both addresses without a separate network/broadcast address.

What is the subnet mask and usable host count for a /24 network?

A /24 prefix sets 24 network bits (subnet mask 255.255.255.0) and leaves 8 host bits, yielding 2⁸ − 2 = 254 usable host addresses.
