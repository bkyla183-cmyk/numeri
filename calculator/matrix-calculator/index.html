How It Works & Mathematical Principles

The Matrix Determinant & Inverse Calculator solves the exact Determinant det(A), Matrix Trace tr(A), and full Multiplicative Inverse Matrix A⁻¹ (or 2×2 Adjugate) for both 2 × 2 and 3 × 3 square real matrices.

A square linear system Ax = b has a unique solution x = A⁻¹b if and only if its determinant det(A) is non-zero. Geometrically, |det(A)| equals the area (in 2D) or volume (in 3D) scaling factor of the linear transformation. When det(A) = 0, the transformation collapses space onto a lower dimension—making the matrix singular with no inverse. This tool switches dynamically between 4-cell 2×2 mode and 9-cell 3×3 cofactor expansion mode.

Governing Equation
A⁻¹ = (1 ÷ det(A)) × adj(A) | Invertible iff det(A) ≠ 0

Step-by-Step Worked Calculation Example

Scenario: Finding the determinant, trace, and inverse A⁻¹ of the 3 × 3 matrix with rows [4, 7, 2], [2, 6, 1], and [1, 0, 3].

  • Evaluate Row 1 cofactors: C₁₁ = 6(3)−1(0) = 18; C₁₂ = −(2(3)−1(1)) = −5; C₁₃ = 2(0)−6(1) = −6.
  • Compute Determinant: det(A) = 4(18) + 7(−5) + 2(−6) = 72 − 35 − 12 = 25 (Invertible; Trace = 4 + 6 + 3 = 13).
  • Transpose full cofactor matrix and divide by 25 → A⁻¹ = [0.72, −0.84, −0.2] | [−0.2, 0.4, 0] | [−0.24, 0.28, 0.4].

Result: det(A) = 25 (Invertible · tr(A) = 13 · Exact A⁻¹ Computed)

Multiplying original matrix A by A⁻¹ reconstructs the 3 × 3 identity matrix I₃ exactly (e.g., Row 1 · Col 1 = 4(0.72) + 7(−0.2) + 2(−0.24) = 1.00).

Forgetting the Transpose Step When Forming the Adjugate Matrix From Cofactors

Dividing the raw cofactor matrix by det(A) without transposing rows and columns produces (A⁻¹)ᵀ instead of A⁻¹ on non-symmetric matrices.

Frequently Asked Questions

What does it mean if a matrix Determinant det(A) equals zero?

When det(A) = 0, the matrix is singular (linearly dependent rows or columns)—its geometric transformation collapses volume to zero, so no unique solution or inverse matrix A⁻¹ exists.

How does the calculator compute the inverse of a 3 × 3 matrix?

It evaluates all nine signed 2 × 2 minor cofactors, transposes the cofactor matrix into the classical Adjugate adj(A), and divides every element by det(A).

What is the Matrix Trace tr(A)?

The trace is the sum of main diagonal elements (a₁₁ + a₂₂ + a₃₃), which invariant-wise equals the sum of all eigenvalues of matrix A.
